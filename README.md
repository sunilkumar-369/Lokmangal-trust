**As well as team help people.**

Official website of **Lokmangal Trust**, a charitable trust that supports elderly people, poor children and families in need with food, clothes, money and care.

## 📖 About the Trust

"Lokmangal" means the welfare of all people. Lokmangal Trust is run by a team of volunteers who believe nobody should go hungry, cold or alone. We help:

- 🧓 **Elderly people**: meals, care and companionship
- 🧒 **Poor children**: food, clothes and support for education
- 🤝 **Poor families**: financial help for medicine and emergencies

Whatever help a person needs, we try to reach them.

## ✨ Website Features

- Front page with the Trust logo and mission
- About section covering food, clothes, financial help and elder/child care
- **UPI donation section**: QR code with a **Donate** button that opens the user's UPI app (PhonePe, GPay, Paytm, BHIM) on mobile
- **Circular photo gallery** that slides automatically from left to right
- **Team section** with names on sliding 3D transparent glass cards
- Fully responsive (mobile, tablet, desktop)
- Pure HTML, CSS and JavaScript, with no build step

## 🛠️ How to Customize

| What | Where |
|------|-------|
| Team member names | `TEAM` list in `index.html` |
| Gallery photos | Add `help1.jpg` to `help8.jpg` in `images/` |
| Donation UPI link | `UPI_LINK` in `index.html` |
| About text | `#about` section in `index.html` |

## 🚀 Deployment

Hosted on **Vercel**, connected to this GitHub repository. Every commit to the `main` branch redeploys the site automatically.
